# Business Management System — User Stories

## 1. Admin
### Authentication and Profile

- As an Admin, I want to log in to the system so that I can access management features.
- As an Admin, I want to log out of the system so that I can securely end my session.
- As an Admin, I want to view and edit my profile so that I can keep my information up to date.
- As an Admin, I want to change my password so that I can maintain the security of my account.

### User Management

- As an Admin, I want to create users so that I can provide employees with access to the system.
- As an Admin, I want to assign roles to users so that I can control their access permissions.
- As an Admin, I want to activate or deactivate users so that I can control access to the system.

### Branch Management

- As an Admin, I want to create branches so that I can add new store locations to the system.
- As an Admin, I want to view branches so that I can see information about store locations.
- As an Admin, I want to edit branches so that I can keep their information up to date.
- As an Admin, I want to delete branches so that I can remove branches that are no longer needed.
- As an Admin, I want to assign employees and products to branches so that business data is organized by location.
- As an Admin, I want to view branch performance indicators so that I can monitor each branch.

### Employee Management

- As an Admin, I want to create employee records so that I can add employees to the system.
- As an Admin, I want to view employee records so that I can access employee information.
- As an Admin, I want to edit employee records so that I can keep employee information up to date.
- As an Admin, I want to delete employee records so that I can remove records that are no longer needed.
- As an Admin, I want to assign employees to branches so that each employee is associated with a workplace.
- As an Admin, I want to search, sort, and filter employees so that I can quickly find the required employee.
- As an Admin, I want to view an employee profile so that I can see detailed information about an employee.

### Shift Management

- As an Admin, I want to create work schedules so that employee shifts can be planned.
- As an Admin, I want to assign an employee to a specific date and time so that work responsibilities are scheduled.
- As an Admin, I want to view schedules by day or week so that I can monitor employee availability.
- As an Admin, I want to manage shift statuses so that shifts can be marked as scheduled, completed, or cancelled.
- As an Admin, I want the system to prevent overlapping shifts so that an employee cannot be assigned to conflicting working hours.

### Category Management

- As an Admin, I want to create product categories so that products can be organized.
- As an Admin, I want to view product categories so that I can see how products are organized.
- As an Admin, I want to edit product categories so that category information can be updated.
- As an Admin, I want to delete product categories so that unused categories can be removed.

### Product Management

- As an Admin, I want to create products so that new products can be added to the system.
- As an Admin, I want to view products so that I can access product information.
- As an Admin, I want to edit products so that product information can be kept up to date.
- As an Admin, I want to delete products so that products that are no longer needed can be removed.
- As an Admin, I want to store a product's SKU, category, purchase price, selling price, stock quantity, and minimum stock level so that the system contains the information required to manage products.
- As an Admin, I want to search, filter, and sort products so that I can quickly find the required product.
- As an Admin, I want to view a product details page so that I can see complete information about a product.

### Inventory Management

- As an Admin, I want to record incoming stock so that product quantities are automatically increased.
- As an Admin, I want to record stock write-offs so that product quantities are automatically decreased.
- As an Admin, I want to view inventory transaction history so that I can track stock movements.
- As an Admin, I want the system to prevent stock quantities from becoming negative so that inventory data remains valid.
- As an Admin, I want to receive a warning when a product reaches a low stock level so that I can react before the product runs out.
- As an Admin, I want the system to prevent a sale when there is not enough stock so that inventory quantities remain correct.

### Sales Management

- As an Admin, I want to create a sale with multiple products so that a complete customer order can be processed in one transaction.
- As an Admin, I want the system to automatically calculate the sale amount so that totals are calculated correctly.
- As an Admin, I want to apply an optional discount to a sale so that discounted transactions can be processed.
- As an Admin, I want to select a payment method so that the payment type is recorded.
- As an Admin, I want to associate a customer with a sale so that the customer's purchase history can be tracked.
- As an Admin, I want the system to automatically decrease product stock after a sale so that inventory remains accurate.
- As an Admin, I want to view sales history so that I can review previous transactions.
- As an Admin, I want to view sale details so that I can see all products and information related to a specific transaction.

### Customer Management

- As an Admin, I want to create customer records so that customer information can be stored in the system.
- As an Admin, I want to view customer records so that I can access customer information.
- As an Admin, I want to edit customer records so that customer information can be kept up to date.
- As an Admin, I want to delete customer records so that records that are no longer needed can be removed.
- As an Admin, I want to view a customer's purchase history so that I can review their previous purchases.
- As an Admin, I want to search and filter customers so that I can quickly find the required customer.

### Income and Expense Management

- As an Admin, I want to record income and expenses so that financial transactions can be tracked.
- As an Admin, I want to categorize expenses so that expenses can be organized.
- As an Admin, I want to record the date, amount, description, and branch for each financial record so that transactions contain the required information.
- As an Admin, I want to view financial totals for a selected period so that I can monitor income and expenses.

### Dashboard and Analytics

- As an Admin, I want to view revenue, sales count, product count, and employee count so that I can monitor key business indicators.
- As an Admin, I want to view products with low stock so that I can identify products that need attention.
- As an Admin, I want to view sales charts by day and month so that I can analyze sales over time.
- As an Admin, I want to view sales by category and top-selling products so that I can understand product performance.
- As an Admin, I want to compare branches so that I can analyze their performance.
- As an Admin, I want to filter analytics by period and branch so that I can analyze specific business data.

### Notifications

- As an Admin, I want to receive notifications about low stock and other important events so that I can respond to issues.
- As an Admin, I want to view notifications in a notification center so that important events are available in one place.
- As an Admin, I want to mark notifications as read so that I can distinguish new notifications from reviewed ones.

### Audit Log

- As an Admin, I want important system actions to be logged so that changes in the system can be tracked.
- As an Admin, I want each audit log entry to contain the user, action, date and time, and affected object so that I can understand what happened.
- As an Admin, I want to view the audit log so that I can review important actions performed in the system.

## 3. Employee
### Authentication and Profile

- As an Employee, I want to log in to the system so that I can access the features available for my role.
- As an Employee, I want to log out of the system so that I can securely end my session.
- As an Employee, I want to view and edit my profile so that I can keep my information up to date.
- As an Employee, I want to change my password so that I can maintain the security of my account.

### My Shifts

- As an Employee, I want to view my assigned shifts so that I know when I am scheduled to work.
- As an Employee, I want to see the date, time, and status of my shifts so that I can track my work schedule.

### Sales

- As an Employee, I want to create a sale with multiple products so that I can process a customer order.
- As an Employee, I want the system to automatically calculate the sale amount so that the total is calculated correctly.
- As an Employee, I want to select a payment method so that the payment type is recorded.
- As an Employee, I want to associate a customer with a sale when necessary so that the purchase can be linked to the customer.
- As an Employee, I want the system to automatically decrease product stock after a sale so that inventory remains accurate.
- As an Employee, I want the system to prevent a sale when there is not enough stock so that invalid sales cannot be completed.
- As an Employee, I want to view the sales information available to my role so that I can perform my daily work.

### Work Data

- As an Employee, I want to view the product information available to my role so that I can process sales correctly.
- As an Employee, I want to search for products so that I can quickly find the required item.
- As an Employee, I want to view available stock quantities so that I know whether a product can be sold.
